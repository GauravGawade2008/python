# Student Marks Data Cleaning Project

## Overview
A beginner Pandas project for cleaning and analyzing student marks data.

## Tasks Performed
- Read CSV data
- Inspected dataset using info() and describe()
- Removed duplicate records
- Cleaned student names
- Filled missing values using:
  - Mean (marks and attendance)
  - Median (age)
- Found students with attendance below 60%
- Calculated average marks
- Displayed top 5 students
- Calculated class average
- Exported cleaned dataset

## Technologies Used
- Python
- Pandas

## Output
Creates a cleaned CSV file named:
`cleaned_student_marks.csv`
